# imot_kirilovi
Автоматичен scraper за новия имот на сем Кирилови

## Други агенции (ERA, Home2U, Явлена)

`agencies.py` тегли обявите от ERA, Home2U и Явлена при всяко пускане на `imot_scraper.py`.

В dashboard-а горната лента е по сайт (`Всички | imot.bg | ERA | Home2U | Явлена`),
а под нея са същите изгледи: Всички активни / Нови / Промени / Продадени.
Филтрите и сортирането по колони работят за всички сайтове.

- **Смяна на търсенето**: филтрираш в сайта на агенцията, копираш адреса и го слагаш
  в GitHub secret `ERA_URL` / `HOME2U_URL` / `YAVLENA_URL`.
- **Нова агенция**: функция `fetch_<име>()`, която връща списък с обяви, и ред в `AGENCIES`.
- Ако някой сайт не отговори, табът му показва данните от предишния път с предупреждение.

## Защита (репото е публично)

- Сайтът е с парола (secret `DASHBOARD_PASSWORD`): `docs/index.html` съдържа само
  криптирания dashboard, който се разкриптира в браузъра след въвеждане на паролата.
- Историите и логът са в репото само криптирани (`*.enc`); некриптирани `*.parquet`,
  `*.csv` и `*.log` не се качват. В публичния лог на GitHub Actions не се печатат обяви.
- Без `DASHBOARD_PASSWORD` или с грешна парола скриптът спира, без да пипа данните.
- **Смяна на паролата**: новата в `DASHBOARD_PASSWORD`, старата в `DASHBOARD_PASSWORD_OLD`
  за едно пускане (данните се прекриптират), после `DASHBOARD_PASSWORD_OLD` се трие.
- **Локално четене на лога/данните**: `python secure_store.py imot_scraper.log.enc`
